# Task

This repository contains a skill definition at
`.agents/skills/greet-user/SKILL.md`. Design and scaffold exactly one new
evaluation task for that skill: a seed repository, a prompt, a deterministic
verifier (or declarative checks), and a judge rubric that together let
someone measure whether having the skill installed actually changes the
outcome for its task.

Commit the new task under `.codev/eval/tasks/<a-name-you-choose>/` in this
repository. When you are done, stop -- do not attempt to run the task
yourself.
